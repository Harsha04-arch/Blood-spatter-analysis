🔧 Manual Computation
Algorithm
1. Filter elongated stains (AR ≥ 1.5)
2. Extract centroid & orientation θ
3. Build trajectory lines:
   p(t) = (cx,cy) + t·(cos θ, sin θ)
4. Compute pairwise intersections
5. Apply RANSAC outlier removal (2σ)
6. Weighted least-squares centroid
7. Report RMS convergence error
